# Glossário de domínio

| Termo | Definição |
|-------|-----------|
| **Planejamento** | Valores previstos para um mês (orçamento). Pertence ao módulo Planning. |
| **Realizado** | Valores efetivamente lançados. Pertence ao Ledger. |
| **Disponível** | Indicador derivado (ex.: planejado − realizado), calculado em Reports — não é entidade. |
| **Categoria** | Agrupamento principal de receita ou despesa (ex.: Moradia). Inativável. |
| **Subcategoria** | Detalhamento de uma categoria (ex.: Aluguel). Inativável. Total de gasto planejado da categoria = soma das subcategorias. |
| **Receita** | Entrada de dinheiro. |
| **Despesa** | Saída de dinheiro. |
| **Transferência** | Movimentação entre contas do mesmo workspace; não é receita nem despesa. |
| **Parcela** | Fração de uma compra parcelada, com competência mensal. |
| **Recorrência** | Regra que gera lançamentos ou itens planejados periodicamente. |
| **Conta** | Conta bancária, carteira ou dinheiro. |
| **Cartão** | Cartão de crédito com limite, fechamento e vencimento. |
| **Competência** | Mês/período a que o valor se refere (pode diferir da data de pagamento). |
| **Data de pagamento** | Data em que o valor foi (ou será) efetivamente pago/recebido. |
| **Workspace** | Espaço financeiro compartilhado (família/grupo). Todo dado financeiro pertence a um workspace. |
